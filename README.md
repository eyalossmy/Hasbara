# הסברה

אתר הסברה ישראלי בעברית: ציר זמן, מיתוס מול מציאות, ארגז כלים לוויכוח, משפט בינלאומי בגובה העיניים, מפת סכסוכים עולמית וחידון.

כל טענה באתר מסומנת לפי רמת הוודאות שלה (עובדה מאומתת / טענה / במחלוקת / לא ידוע / מתפתח) ומגיעה עם מקורות.

## פיתוח

```bash
npm install
npm run dev
```

## מבנה

- `src/data/`, כל התוכן (ציר זמן, טענות, ארגז כלים, חידון, מילון, משפט, סכסוכים, מקורות)
- `src/pages/`, העמודים
- `src/styles.css`, מערכת העיצוב

מצאתם טעות? פתחו Issue.

## כללי כתיבה

באתר אין מקפים כסימן פיסוק (— או –). משתמשים בפסיק, בנקודתיים או בנקודה. `npm run build` נכשל אם מקף כזה נכנס.
